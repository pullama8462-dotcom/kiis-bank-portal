# Public deployment (KIIS Bank Portal)

## Stack

- **Frontend:** React 18 + Vite 5 + Tailwind (3D via Three.js / React Three Fiber)
- **Backend:** FastAPI + SQLAlchemy + PostgreSQL (SQLite for local dev)
- **Production (recommended):** Docker Compose + nginx (`README_DEPLOY.md`), or **Render** blueprint (`render.yaml`)

## Quick public URL (temporary demo)

While `uvicorn` and `cloudflared` are running on your machine:

```powershell
cd c:\Users\Himam\.gemini\antigravity\scratch\kiis-bank-portal\backend
$env:DATABASE_URL = "sqlite:///./kiis_bank.db"
.\win_env\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# In another terminal:
npx --yes cloudflared tunnel --url http://127.0.0.1:8000
```

The tunnel prints a `*.trycloudflare.com` URL. It stops when you close the processes.

## Permanent hosting on Render (free tier)

1. Push this repo to GitHub (do not commit `.env`).
2. Open [Render Blueprints](https://dashboard.render.com/blueprints) → **New Blueprint Instance** → connect the repo.
3. Render provisions **Postgres** and the **web service** from `render.yaml`.
4. After deploy, open your `*.onrender.com` URL.

### Environment variables (Render sets most automatically)

| Variable | Required | Notes |
|----------|----------|--------|
| `DATABASE_URL` | Yes | Linked from Render Postgres (`kiis-db`) via blueprint |
| `SECRET_KEY` | Yes | Auto-generated by blueprint; used for JWT |
| `JWT_SECRET` | Optional | Alias; `SECRET_KEY` is preferred |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Optional | Default `60` |
| `POSTGRES_*` | Docker only | Used by `docker-compose`, not Render web service |

Seed runs on each deploy start (`python seed.py` in `render.yaml`). Demo users are created only if the DB is empty.

## Why not Vercel/Netlify alone?

The app needs a **Python API** and **database**. Static hosts only serve the Vite build; API calls use `window.location.origin` and expect `/api/*` on the same host (nginx or FastAPI serves both).

## Vercel / Railway CLI

CLI login is required (`npx vercel login`, `npx @railway/cli login`). Use Render blueprint or Docker on a VPS if you prefer no CLI auth on this machine.
